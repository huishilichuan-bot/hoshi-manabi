プライバシーポリシー

制定日：2026年11月17日

ほしまなび（以下「本アプリ」）は、勉強の記録を守ることを大切にしています。このページでは、本アプリがどんな情報を、どこに、なんのために保存するかを説明します。
小学生・中学生の人は、おうちの人といっしょに読んでね。

1ゲストで使うとき（ログインしないとき）

記録は、すべてお使いの端末のブラウザの中（localStorage）だけに保存されます。本アプリの運営者を含め、外部に送られることはありません。

2ログインしたときに保存する情報

アカウントを作ってログインすると、次の情報を Google が提供する Firebase（Firebase Authentication と Cloud Firestore）に保存します。

  • アカウントの情報：メールアドレス、ログインの方法（メールアドレス／Google）、Firebase が発行するユーザーID。メールアドレスで登録した場合のパスワードは Firebase が安全な形で管理し、運営者が見ることはできません。
  • Google でログインした場合：Google から受け取るメールアドレス・名前・プロフィール画像のURL（Firebase Authentication に記録されます。本アプリの画面で使うのはメールアドレスだけです）。
  • 学習の記録：⭐の数、クリアしたステップと成績、ガチャで出たなかま・称号・着せかえ、まちがえた問題ボックス、ゲームの記録、毎日の記録、ニックネームや音などの設定、「この問題おかしい？」で保存した報告。

Firebase は、ログインを守るために IPアドレスや端末の種類などの技術的な情報を処理することがあります。

3使う目的

  • ログインできるようにするため
  • 学習の記録をアカウントに保存し、ほかの端末でも同じ記録で使えるようにするため（同じアカウントでログインしている端末どうしで、記録を自動で同期します）
  • パスワードの再設定メールを送るため

これ以外の目的には使いません。

4しないこと

  • 広告は表示しません。広告のために情報を使いません。
  • 情報を売ったり、ほかの会社にわたしたりしません（下の Google／Firebase をのぞく）。
  • お金の支払い・課金の機能はありません。
  • 位置情報・連絡先・写真・マイクは使いません。英語の読み上げは端末の機能で再生するだけで、声を録音することはありません。
  • アクセス解析ツールは使っていません。

5情報をあずける先（Google／Firebase）

保存とログインには、Google LLC が提供する Firebase を使います。情報は Google のサーバー（日本以外の国にある場合があります）に保存され、Google は本アプリのために情報を処理します。くわしくは Firebase のプライバシーとセキュリティ と Google プライバシーポリシー をご覧ください。

本アプリのページは GitHub Pages で公開しています。ページを開くとき、GitHub がアクセスの記録（IPアドレスなど）を処理することがあります。

6端末の中に保存するもの

本アプリは、記録や設定を端末の localStorage に保存します。ログインしている間は、アカウントの記録のコピーを端末に置き（オフラインでも使えるようにするため）、ログイン状態を保つために Firebase が端末の IndexedDB などに情報を保存します。ログアウトすると、そのアカウントの記録のコピーとログイン状態を端末から消します。ゲストの記録はアカウントの記録とは別に保存します。オフラインで使えるように、アプリのファイルを端末にキャッシュします。

7記録の安全

クラウドの記録は、ログインした本人だけが読み書きできるように設定しています。通信は暗号化（HTTPS）されています。

8記録の確認・削除

  • アカウントとクラウドの記録の削除：マイページ →「アカウントを削除する」から、いつでも削除できます。クラウドの記録とアカウントが消え、もとにはもどせません。
  • 端末の中の記録の削除：マイページ →「すべてのデータを消す」から削除できます。
  • 自分で削除できないときや、記録について知りたいときは、下の問い合わせ先に連絡してください。

9子どもの利用について

本アプリは小学生・中学生の学習用です。お子さまがアカウントを作るときは、保護者の方がこのプライバシーポリシーと利用規約を読み、同意したうえで使ってください。保護者の方は、上の方法でいつでもアカウントと記録を削除できます。

10このポリシーの変更

内容を変えるときは、このページで知らせます。大切な変更のときは、アプリの中でもお知らせします。
