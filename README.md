# ほしまなび

小1〜中3の「算数・数学／国語／生活／理科／社会／英語」を、短いステップで学ぶ無料の学習アプリ（PWA）。iPhone・iPad の Safari で開いて「ホーム画面に追加」すると、アプリのように使えます。オフラインでも動きます。

- 教科 → 学年 → 単元 → ステップ → 問題。1ステップは約7分。ステップの中でも、単元の中でも、やさしい → むずかしい。
- すべての問題に解説。正解は大きな⭕とピコーン音。まちがえたら正解と解説。
- 6割以上（切り上げ）で⭐1こ＋ガチャ1回。6割未満はまちがえた問題だけやり直して、合わせて6割になった時点で⭐。⭐は減らない。2秒以内の回答は「ちゃんと読んでね」で止める。
- ⭐は毎日リセット。その日に⭐4こでゲーム（50種）がひらく。ゲームでのごほうび・有利はなし。
- なかまガチャ（40種・7レア度・確率表示）。ごほうびは見た目だけ。課金なし。
- 「この問題おかしい？」の報告は端末内に保存、設定から一覧・書き出し。

## 開発

```
node tools/verify.js 40     # 問題の自動検証（算数・数学は独立した有理数計算で答えを再計算）
python3 -m http.server 8080 # ローカルで確認
```

データは localStorage（キー `hoshimanabi`、schema 1）に保存。サービスワーカーのキャッシュ名は `hoshi-manabi-v1.1.0`。

## v1.3.0 の主な変更
- アカウント（Firebase・無料の Spark プランのみ）：Googleで続ける／メールアドレス（新規登録・ログイン・パスワード再設定）／あとで（ゲスト）
- 記録をクラウド（Firestore users/{uid}）に保存して、ほかの端末でもつづきから。はじめてのログインでは端末の記録とクラウドの記録を合わせる（⭐は多い方、なかまは両方）
- クラウドへの書きこみは、ステップの終わり・アプリをかくした／とじたとき・ガチャやボス勝利のあと（3分以内はまとめる）だけ。内容が同じなら書かない（v1.3.1）。オフラインでもOK
- マイページ：アカウント欄（メール・同期状態・今すぐ保存・ログアウト・アカウント削除）
- privacy.html（プライバシーポリシー）・terms.html（利用規約）、firestore.rules（本人だけ読み書き）
- 設定は firebase-config.js（enabled:false でログイン機能を止められる）

## v1.2.0 の主な変更
- **まとめカード**：すべてのステップの最初に「今日のポイント」（図つきのれい・こたえ・解説、相棒のひとこと）
- **新しい問題形式**：並べかえ・線でつなぐ・カード合わせ・図をタップ（タッチ操作・2秒ルールあり）。算数・国語・英語・理科・社会の各学年に配置
- **図（インラインSVG・オリジナル）**：時計・分数・角度・三角形・座標・1次関数のグラフ／こん虫・花・人の体・月・回路・てこ・温度計／かんたんな日本地図（8地方）・六大陸・八方位／英語の絵カード
- **コンボ**：3・5・10問連続正解でだんだん大きくなる演出とコンボゲージ
- **ステップマップ**：単元ごとのすごろく風の道。合格したステップが光り、今のステップに相棒が立つ
- **まちがえた問題ボックス**：まちがえた問題がたまり、正解すると消える（⭐はふえない）
- **英語の読み上げ**：🔊ボタン（en-US）と聞きとり問題。読み上げできない端末では英語を文字で表示
- **ボス問題**：単元の最後のまとめバトル（HPバー・攻撃演出）。勝つと見た目だけの「かんむり」と称号
- **学習指導要領の監査**：tools/curriculum.json（310項目）と tools/audit.js。結果は tools/coverage.json の audit
- **アプリらしい見た目**：下タブ（ホーム／学ぶ／ゲーム／なかま／マイページ）、大見出しの上バーと前の画面名つきの戻る、画面遷移アニメ、起動画面、押した感、音量設定、マイページ
- テスト：`node tools/verify.js 20`、`python tools/test_app.py`、`python tools/test_v12.py`
