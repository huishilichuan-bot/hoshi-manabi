# ほしまなび

小1〜中3の「算数・数学／国語／生活／理科／社会／英語」を、短いステップで学ぶ無料の学習アプリ（PWA）。iPhone・iPad の Safari で開いて「ホーム画面に追加」すると、アプリのように使えます。オフラインでも動きます。

- 教科 → 学年 → 単元 → ステップ → 問題。1ステップは約7分。ステップの中でも、単元の中でも、やさしい → むずかしい。
- すべての問題に解説。正解は大きな⭕とピコーン音。まちがえたら正解と解説。
- 6割以上（切り上げ）で⭐1こ＋ガチャ1回。6割未満はまちがえた問題だけやり直して、合わせて6割になった時点で⭐。⭐は減らない。2秒以内の回答は「ちゃんと読んでね」で止める。
- ⭐は毎日リセット。その日に⭐4こでゲーム（50種）がひらく。ゲームでのごほうび・有利はなし。
- なかまガチャ（40種・7レア度・確率表示）。ごほうびは見た目だけ。課金なし。
- 「この問題おかしい？」の報告は端末内に保存、設定から一覧・書き出し。

## 開発

```
node tools/verify.js 40     # 問題の自動検証（算数・数学は独立した有理数計算で答えを再計算）
python3 -m http.server 8080 # ローカルで確認
```

データは localStorage（キー `hoshimanabi`、schema 1）に保存。サービスワーカーのキャッシュ名は `hoshi-manabi-v1.1.0`。
